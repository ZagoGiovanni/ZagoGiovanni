## 🚀 Projeto em destaque

### Pegada Kids

Plataforma web desenvolvida a partir de uma necessidade real de uma loja de roupas infantis. O sistema reúne uma vitrine virtual para clientes e um painel administrativo para a gestão da loja.

Principais recursos:

- catálogo de produtos com categorias, pesquisa e estoque por tamanho;
- carrinho, pedidos pelo WhatsApp e pagamentos Pix integrados ao Mercado Pago;
- cadastro e autenticação de clientes;
- painel administrativo para produtos, clientes, pedidos e estoque;
- listas de presentes para chá de bebê com compartilhamento por link;
- consulta de CEP e endereço de entrega.
